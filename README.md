# Apple Podcasts for MyGo Music

在 MyGo Music 中使用苹果播客账号。**0.2.0-preview.2 使用 MyGo 原生播放，并修复资料库页面不刷新的问题；有效登录下不需要 Chrome 运行。**

已验证保存现有登录、重启恢复、免费单集原生播放、云端续播、暂停/倒退位置写回。会员专属音频与真实手机交替续播仍未验收，当前为开发预览，详见[验证记录](docs/VALIDATION.md)。

## 安装与升级

目前提供 Windows x64 预览。下载 [Releases](https://github.com/AceYKN/mygo-music-apple-podcasts/releases) 中的：

- `apple-podcasts-windows-amd64.zip`：在 MyGo“设置 → 插件 → ＋”选择本地 ZIP 安装，允许该插件启动辅助程序。
- `MyGo-Music-native-progress-windows-amd64.zip`：基于官方 MyGo 0.1.22 的配套构建，增加通用播放进度回调，保留原来的数据目录。

当前官方 0.1.22 没有持续进度接口。只安装插件可以原生播放，但准确续播和进度上传需要配套 MyGo；缺少接口时首页会说明。宿主修改及完整对应源码一同公开，见 [host-patch](host-patch/README.md)。

从 preview.1 升级时，请同时更换本版配套 MyGo：旧配套版本的“关注的节目”只加载一次，即使主页已读到新列表，侧栏也可能保留旧列表。插件会提示旧宿主缺少自动刷新能力。

从上一版升级会自动导入已有专用会话，成功保存后关闭登录浏览器。无需重新输入账号。首次登录或确需重新验证时才使用已安装的 Chrome；所有登录浏览器都静音。播放音量由 MyGo 自己控制。

## 登录保持

Windows 使用当前系统账号的 DPAPI 加密保存会话，重启 MyGo 或辅助程序不会主动清除它。

- 正常请求直接使用保存的凭据，不启动浏览器。
- 接受苹果 API 响应中续发的凭据，并防止旧请求覆盖新会话。
- 开发者配置从官网公开资源更新，不为更新配置而打开 Chrome。
- 超时、断网和限流保留登录与最后成功资料；仅账号校验明确拒绝授权时，才有限度地尝试静默恢复。
- 静默恢复结果须经账号接口确认，失败不会覆盖先前保存的登录。

有效期仍由苹果决定；修改密码、撤销授权或苹果强制验证时可能需要重新登录，不能保证永久有效。

数据通常保存在 `%APPDATA%\MyGo Music\plugin-data\apple-podcasts`。请保留 `session.bin` 和 `browser-profile`。显式退出会清除插件保存的用户凭据与当前账号同步资料，并记录退出状态，避免重启时自动接回。

## 播放与同步

- 关注、已存单集、继续播放、最新单集与搜索读取苹果数据；关注/保存/完成状态写后读回。
- 音频地址交给 MyGo 原生解码播放，音频服务器不会收到苹果账号认证头。
- 播放前读取最新云端位置；暂停、定位、切集、结束、退出及播放中的定时回调提供真实位置。
- 新进度先写入本机日志，再由后台接口上传，避免网络请求阻塞播放。较小的倒退位置不会被“取最大值”覆盖。
- 未确认和冲突操作显示在“播放与同步”，供明确重试或放弃。账号变更时拒绝旧账号的播放事件。
- 从头播放可将 MyGo 播放条拖到开头；手动定位优先于迟到的云端续播结果。
- 资料库在前台每 30 秒重新读取，切回窗口立即刷新；关注页、首页、已存单集与当前自定义资料页按账号接口更新，反映新增和移除。后台窗口不持续轮询。
- 关注页刷新时保留原内容；网络或地区异常会显示错误并可重试，迟到的旧账号/旧请求不能覆盖新的列表或本机关注操作。

## 当前边界

### 关注节目缺失或跳到中国区

Clash 等代理的规则可能让 `apple.com` 直连，而其他请求走代理。实测这种路由会使外区节目页面跳到 `/cn/new`，账号接口也可能隐藏部分已关注节目。账号未退出，缺项本身不能证明手机和网页没有同步。

请检查 `podcasts.apple.com`、`amp-api.podcasts.apple.com` 及相关认证请求实际命中的代理规则，使外区访问走预期的同一网络出口。修正后，在左下角账号菜单进入“我的主页”重新读取，无需取消关注或重新登录。插件发现地区跳转时会提示，并优先保留此前成功读取的资料库；该探测属于辅助诊断，无法识别所有网络过滤。

### 尚未完成的验收

会员专属单集保留为正式版要求，但尚无真实权益样本完成验收。受保护或分段格式尚未验证时明确报错，不切回 Chrome 播放，也不把预告当完整音频。

“继续播放”不等于全部历史；频道/权益界面、自然会话过期、多账号实测、真实多设备冲突、大资料库及长时稳定性仍需完善。正式范围见 [PRD](docs/PRD.md)。

## 开发

插件使用 TypeScript、esbuild、Go；Chrome 只负责登录获取与必要恢复。辅助程序仅监听 127.0.0.1 随机端口并校验临时凭证，凭据不进入源码、命令行或普通日志。

需要 Node.js 24+、辅助程序 Go 1.25+。修改 MyGo 宿主需 Go 1.27.3。运行 `npm ci --ignore-scripts`、`npm run check`、`npm test`、`npm run build`，再在 helper 和 tests/runtime 下运行 `go test ./...`；最后执行 `npm run helper:build` 与 `npm run package`。

设计依据与借鉴的实现见[技术规格](docs/TECH_SPEC.md)和[参考设计](docs/REFERENCE_DESIGN.md)。项目与 Apple、Google、MyGo Music 均无官方关联。
