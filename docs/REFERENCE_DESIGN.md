# 参考实现与采用的设计

审阅日期：2026-11-10。参考本机安装的网易云、YouTube Music 插件，以及已取得的 Overcast 插件源码快照。以下记录采用的实现思路，不声称它们提供 Apple Podcasts 的接口或会员播放能力。

| 来源 | 观察到的设计 | 本项目的采用方式 |
| --- | --- | --- |
| 网易云 | 保存有效会话，接受响应中续发的 Cookie | 苹果会话用 Windows DPAPI 保存；API 续发的有效凭据保留原账号标识 |
| 网易云 | 处理响应前核对发起请求的会话，隔离迟到结果 | 旧请求不能覆盖新登录；原生播放事件绑定账号上下文 |
| 网易云 | 账号校验短期缓存；相同播放解析请求合并 | 账号状态缓存 45 秒，进入首页强制刷新；同代次、同单集的进行中请求合并 |
| 网易云 | 限定重试范围，拒绝把权限失败变成别的来源或试听成功 | 不盲目重放写入；写后读回，失败进入待确认或冲突状态 |
| YouTube Music | 登录页面只负责拿会话，stream 返回给 MyGo 播放 | 登录与播放拆开；日常播放走 MyGo stream，Chrome 不参与音频 |
| Overcast | 从单集 enclosure 返回 URL、格式、长度 | 苹果目录提供的直接音频交 MyGo；未知格式用不带账号凭据的短请求识别 |
| Overcast | 账号数据与本地 recent/liked 分开 | 保留苹果真实资料库和进度，不把本机记录冒充苹果历史 |

苹果接口的请求头、写入方法与进度数据来自苹果官网的实际实现和本项目读回验证，不从其他服务照搬。会员专属音频仍需独立验证。

与 [MyGo 0.1.22 插件协议](https://github.com/egoist/mygo-music/blob/v0.1.22/README.md#plugins)相比，持续进度和云端续播缺少宿主接口，因此另提供通用的 playbackStart/playbackProgress 补丁。它只向当前来源发送自身音频的状态，未实现这些导出的插件保持原有行为。
