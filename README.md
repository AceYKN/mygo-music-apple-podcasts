# Apple Podcasts for MyGo Music

计划为 [MyGo Music](https://github.com/egoist/mygo-music) 接入 Apple Podcasts：使用苹果账号登录，双向同步资料库和收听状态，并播放账号已有权限的免费及付费单集。

**当前处于需求和技术设计阶段，尚未提供可安装的插件。** 已验证官方网页登录、个人关注列表和“继续播放”接口；完整同步及音频播放仍需开发和验收。

## 已确认的目标

- 在苹果官方页面登录，重启后恢复会话。
- 同步关注节目、已存单集、已播放状态、播放位置和继续播放列表。
- 在 MyGo 操作后同步到苹果端，在苹果端修改后同步回 MyGo。
- 账号已订阅或购买、当前仍有权限收听的付费单集，也能完整播放。
- 在 MyGo 内完成浏览、播放控制和断点续播；免费与付费单集采用一致的操作方式。

推荐的实施路线是 TypeScript 插件、Go 辅助程序和专用 Chrome 会话。官方播放页负责授权播放，MyGo 负责展示与遥控。该路线尚需验证，不能把设计目标视为已经实现的能力。

首个验收平台为 Windows x64。项目与 Apple、Google、MyGo Music 均无官方关联。
