# 验证记录：0.2 原生播放

日期：2026-11-10 · 版本：0.2.0-preview.1。上一版遥控播放的记录保存在 [VALIDATION_REMOTE_0.1](VALIDATION_REMOTE_0.1.md)，不将旧方案的成功当成新版已通过。

## 环境

Windows x64、MyGo 0.1.22 加通用进度回调补丁、Go 1.27.3 宿主工具链、Go 1.25.1 辅助程序、Node 24.11.0。真实测试使用公开免费单集与实际苹果账号接口，音频由 MyGo 原生播放器解码，测试音量为 0。

## 已通过

| 检查 | 实际结果 |
| --- | --- |
| 登录迁移 | 从此前已登录的专用配置导入，成功保存为 Windows DPAPI 加密会话；未要求用户再次输入账号 |
| 重启保持 | 实际辅助程序连续两次启动，账号校验成功，均无遗留 Chrome 子进程 |
| 日常接口无 Chrome | 原生预览的资料与播放准备调用完成后，诊断 browserRunning=false、chromePlayback=false |
| 实际 MyGo 重启 | 用户退出并重新打开已更新的 MyGo，苹果播客来源恢复登录，真实界面显示“继续播放”和“关注的节目”，插件专用 Chrome 进程数为 0 |
| 原生音频 | 加载真实公开 MP3，MyGo 原生音频对象存在，remote 播放对象为空，音量设为 0 |
| 云端续播 | 苹果端测试位置为 45 秒时，原生播放器加载后也从 45 秒开始 |
| 暂停与主动倒退 | 原生定位到 120 秒、暂停、再倒退到 30 秒；通过苹果接口重新读取为 30000 毫秒 |
| 测试恢复 | 测试后将该单集恢复到测试前的已确认位置，操作日志无未确认项 |
| 时钟偏差 | 实测 API 时钟比本机快约 4 秒；加入 Date/往返时间校正，修复自身写入被误判为冲突，新增对应回归测试 |
| 静音 | 认证浏览器始终 mute-audio；实际原生播放器测试音量为 0 |
| 网络地区恢复 | 同一有效账号在原路由下出现外区节目跳转和关注列表缺项；修正代理路由后，重用原加密会话读取恢复，无需再次登录或重新关注 |

上述真实原生回归由 MyGo 源码中的 opt-in 测试驱动实际插件、辅助程序和原生播放器，非只模拟返回值。常规测试不会自动访问真实账号。

## 保留的缺口

会员专属单集仍无真实权益样本，未验收；受保护或分段格式不宣称可用。真实手机交替播放、自然登录到期、多账号真实切换、完整单集自然结束、长期运行、真实双设备冲突、大资料库和干净环境安装仍需验证。

当前正式 MyGo 0.1.22 不提供持续位置回调，需配套补丁实现完整原生续播/上传。这个依赖必须在说明与插件界面中显示，不能在普通宿主上假称已同步。

测试不公开账号标识、私人列表、Cookie、令牌、浏览器配置或加密会话文件。正式版条件不因预览调整而删除，见 [PRD](PRD.md)。
