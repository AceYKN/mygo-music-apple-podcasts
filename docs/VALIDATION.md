# 可行性验证记录

日期：2026-11-10。本文只记录已经发生的验证；[PRD](PRD.md) 和[技术规格](TECH_SPEC.md)描述后续目标。

## 已通过

| 检查 | 实际结果 |
| --- | --- |
| 独立 Chrome 中打开 Apple Podcasts 官方网页 | 页面可用，用户可自行完成登录 |
| 登录状态 | 官方播放器显示已授权；产生 `media-user-token` Cookie |
| Cookie 与请求头 | Cookie 值与官方请求中的同名 `media-user-token` 头一致 |
| `/v1/me/storefront` | 独立请求返回 HTTP 200 |
| `/v1/me/library/podcasts` | 独立请求返回 HTTP 200，取得真实关注列表 |
| `/v1/me/continue-playing/podcast-episodes` | 独立请求返回 HTTP 200，取得继续播放数据 |
| 缺少用户令牌的个人资料库请求 | HTTP 403，未取得个人资料 |
| 卸载官方网页后重放读取请求 | HTTP 200；独立请求上下文不带浏览器 Cookie |
| 公开目录与 RSS | 部分样本可搜索并取得 RSS，能解析单集 enclosure |

测试使用官网开发者令牌和从官方登录取得的用户令牌，没有将凭据写入本仓库。公开记录不包含个人节目列表、账号标识、Cookie、令牌或浏览器会话文件。

## 可据此得出的结论

官方网页会话可以用于读取账号资料库，账号接入值得继续开发。当前结果不能证明完整同步、会员播放或成品插件已经可用。此前其他项目无法复用 MusicKit 凭据的经验，也不能替代本项目对具体网页会话和请求头的实测。

采用官方浏览器播放并接入 MyGo `remote` 的路线是为了覆盖完整同步和会员播放需求，仍须单独验证。浏览器能登录不等于受保护音频已通过；MyGo 能显示当前位置也不等于苹果云端已收到该位置。

## 宿主基线

已查阅 MyGo Music v0.1.22，提交 `1af0d8efd77fdf630c27cfc635f12e9cb089ce10` 的插件接口与资料模型。该版本支持网页 Cookie 登录、播客列表和 remote 控制；`played` 回调只提供单集 ID。

后续每次实际验证需要补充日期、提交、运行环境、动作、结果和证据。脱敏后才能提交公开仓库，不将外部说明中的“支持”直接记为本项目测试通过。
