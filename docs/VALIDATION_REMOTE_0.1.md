# 验证记录

日期：2026-11-10 · 版本：0.1.0-preview.1。仅记录已发生的检查；正式要求见 [PRD](PRD.md)。

## 环境和方法

Windows x64，MyGo Music 0.1.22（宿主基线提交 `1af0d8efd77fdf630c27cfc635f12e9cb089ce10`），Chrome 156.0.8078.80，Node 24.11.0，Go 1.25.1。

真实测试使用实际 Go 辅助程序、专用 Chrome 登录目录与 Apple Podcasts 官方服务；插件入口另由开发宿主驱动。自动测试使用合成资料。开发驱动通过不等于 MyGo 图形界面验收通过。

播放验收使用浏览器级 `--mute-audio`，没有向使用者播放声音。公开记录不含私人节目列表、账号指纹、Cookie、令牌或浏览器资料。

## 真实环境已通过

| 检查 | 实际结果与边界 |
| --- | --- |
| 官方登录 | 用户自行完成登录，辅助程序取得有效会话，账号接口确认有效 |
| 重启恢复 | 关闭并重开实际辅助程序后恢复登录；改用 MyGo 永久数据目录后也恢复，无需再次输入密码 |
| 账号读取 | storefront、关注列表、继续播放返回 200；开发宿主可通过发布入口生成首页 |
| 搜索/节目页 | 真实节目搜索和节目单集读取通过；实际第二页可读，更多分页由合成测试补充 |
| 关注写入 | 经用户允许临时关注《故事FM》，服务端读回确认，再取消并读回，恢复原先未关注状态 |
| 保存写入 | 临时保存选定单集，读回确认，再取消并读回，恢复原先未保存状态 |
| 完成状态 | 选定单集的 completed=true/false 均经服务端读回，结束时恢复未完成 |
| 免费播放 | Talk Python To Me 的公开单集由官方播放器加载，HTML 媒体 readyState=4；位置推进、时长与真实播放器一致，全程静音 |
| 精确位置 | 定位到 120000 毫秒并暂停，等待官方上报后，账号 API 读回同一位置 |
| 续播 | 发布入口 remotePlay 在默认位置为 0 时，使用云端的 120000 毫秒续播 |
| 主动倒退 | 拖回 30000 毫秒并暂停，服务端随后确认较小的位置，未被取最大值覆盖 |
| 后台加载修正 | 冷启动时在已最小化窗口中加载可能超时；改为加载时短暂展开，play 成功后最小化，实际发布入口返回成功后，后台位置由 30000 推进到 184000 毫秒 |
| 控制与位置回归 | 最小化时的控制曾返回成功但云端不一致；改为控制时短暂展开、等待实际媒体确认，状态优先使用 HTML 媒体时间。最终回归：实际音频从约 120.005 秒推进到 123.017 秒，窗口确认最小化；暂停后约 123.063 秒；倒退并暂停在 30 秒，随后苹果端读回 30000 毫秒 |
| 强制退出清理 | 独立测试配置中强杀辅助程序；Windows Job Object 清理其 Chrome 进程，未影响日常 Chrome |

关注和保存测试均已恢复原状态。播放与定位测试会按正常收听行为影响所选免费单集的云端进度，不把此行为描述为完全没有账号变更。

- Node 9 项：链接校验、毫秒/节目资料映射、保留会员 offers、云端续播/倒退/从头播、分页去重、账号变更清缓存、辅助程序握手及默认静音。

- `go vet ./...` 通过。CI 的跨系统结果需查看对应提交的 Actions，不能把本机结果写成 CI 通过。
